# NuSrcAgent: An AI Agent for High-Energy Neutrino Source Searches

[arXiv link when it is available.]

Read the paper for details on the neutrino data, likelihood methods, architecture of NuSrcAgent, comparisons with IceCube results, and more. 

You can also chat with NuSrcAgent directly for anything you would like to learn about it and how to use it. 

NuSrcAgent helps researchers search public IceCube point-source data for high-energy neutrino emission from individual sources or source catalogs. Start with a source name, sky coordinates, or a catalog. Describe your analysis to an AI assistant in natural language or run it from a terminal. Both use the same likelihood code to compute the numerical results, and NuSrcAgent saves the inputs, settings, and results so you can repeat the analysis. You can ask the agent to search the literature, review the methods used in previous studies, or fit a non-power-law spectrum generated by your own model code. For analyses beyond the built-in workflows, the agent can write and run new code, as it did for the paper’s signal-injection simulations for flux upper limits.

## Get started

### Install with Claude Code or Codex

Open the folder that will contain the NuSrcAgent checkout. In Claude Desktop,
open the **Code** tab and select **Local**. In Codex, select **This computer**.
Send this prompt.

```text
https://github.com/beizhouphys/NuSrcAgent install this
```

The assistant runs `bash install.sh` from an existing NuSrcAgent GitHub
checkout or clones the repository into a new directory in the selected folder
and runs it there. It reports the install path after input verification passes.
If a download fails, it reports the failed step and host.

After installation, open the `NuSrcAgent` folder in a Local session.

```text
Analyze NGC 1068
```

The agent looks up NGC 1068 and runs a time-integrated fit using all 14 years of IceTracks-DR2. To invoke the skill by name, use `$nusrcagent` in Codex or `/nusrcagent` in Claude Code.

### More details about installation

NuSrcAgent `1.0.0` is the version described in the paper. It runs on macOS and Linux.
You need Git and internet access. The installer uses an existing Python 3.12
or downloads one into the project folder. On Apple Silicon it uses native
arm64 Python. You can install without a GitHub account.

To install from a terminal, run

```bash
git clone https://github.com/beizhouphys/NuSrcAgent.git
cd NuSrcAgent
bash install.sh
```

The installer downloads and verifies the IceTracks-DR2 data and precomputed probability density function (PDF) tables. The default download is **1.52 GB** and takes up **3.8 GiB** after extraction. Allow extra space for the Python environment, cached downloads and staging files.

After extraction, IceCube event data, detector uptime and detector response files occupy about 2.61 GB. The PDF tables take up another 1.44 GB. The tables speed up likelihood evaluation by letting each fit look up precomputed distributions. The raw IceCube files compress well, so the PDF tables account for about 91% of the download.

To add IceTracks-DR1, run `bash install.sh --data-sample icecube_public_ps_10yr`. See [installation options and recovery](docs/input_installation.md), [data attribution](docs/data_attribution.md) and the [terminal examples](docs/quickstart.md).

## What analyses can I run?

- **Single-source analysis** tests for a neutrino excess at one sky position.
- **Catalog-wide single-source analysis** fits each source independently, giving one result per source.
- **Stacking analysis** tests a catalog’s combined emission. Choose a weighting scheme, such as equal weighting or weighting by a measured source flux. The fit accounts for detector acceptance at each source position.

With the default IceTracks-DR2 data, you can run each of these analyses in either of two time modes.
- Use a **time-integrated analysis** to test for emission across the selected observation periods, pooling events over time.
- Use a **time-dependent analysis** to test for a flare or other time-varying emission using event arrival times.

| Data and analysis | What you can test |
| --- | --- |
| IceTracks-DR2 (2008–2022), time-integrated | All three analyses. The default fit uses event directions and energy proxies. You can also request a spatial-only fit. |
| IceTracks-DR2, time-dependent | All three analyses with a fixed box or Gaussian time profile for each source. For one source or for each catalog source independently, you can also request a [fitted-time search](docs/time_dependent.md). |
| IceTracks-DR1 (2008–2018), time-integrated | Spatial-only single-source analysis, or a catalog-wide single-source analysis with stacking. |

## Examples from the paper

- **NGC 1068.** We gave the agent turbulent corona model code and compared the resulting non-power-law fit with a power-law fit in a time-integrated analysis. To test your own model, supply a table of energy and differential flux for a fixed spectral shape. See [spectrum inputs](docs/requested_spectra.md).
- **32 magnetars.** We asked the agent to find an IceCube stacking analysis in the literature and fit the same 32 magnetars with equal weighting. To reproduce the study’s flux upper limit, the agent wrote signal-injection simulations for this comparison.

Try both catalog analyses with the [three-source example](docs/quickstart.md#2-three-source-scan-plus-stack). You can also use the [catalog of 3,386 radio-bright AGN](data_input/sources/README.md).
