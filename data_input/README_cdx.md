# Local Data Directory

Large LLH inputs are not tracked by Git. Obtain `NuSrcAgent_data_v0.2.0_cdx.tar.gz` from the project owner, extract it at the repository root, and run:

```bash
python3 verify_private_alpha_setup_cdx.py --hashes
```

See `DATA_SETUP_cdx.md` at the repository root for provenance and handling rules.
